# Pacote de Ícones de Bancos Brasileiros

[![](https://data.jsdelivr.com/v1/package/gh/matheusmcuba/icones-bancos-brasileiros/badge)](https://www.jsdelivr.com/package/gh/matheusmcuba/icones-bancos-brasileiros)

Conjunto de ícones dos mais diversos bancos brasileiros.

![Screenshot](https://i.imgur.com/cBVzDi0.png)

## Bancos incluídos

- Caixa Econômica Federal
- Santander
- Itaú
- Banco do Brasil
- Bradesco
- Sicoob
- Sicredi
- e diversos outros!

## Como usar

### CDN (online)

Adicione o CSS no seu HTML:

```html
<link rel="stylesheet" href="https://cdn.jsdelivr.net/gh/matheuscuba/icones-bancos-brasileiros@1.1/dist/all.css">
```

> Se você estava usando a URL antiga do CDN, atualize para a URL acima. O nome de usuário do repositório mudou.

### Webfont (local)

1. Baixe os arquivos de fonte da pasta `dist`.
2. Baixe o arquivo `icones-bancos-brasileiros.css`.
3. Adicione o CSS externo:

```html
<link rel="stylesheet" href="caminho/para/icones-bancos-brasileiros.css">
```

4. Comece a utilizar os ícones.

### Aplicações desktop

1. Baixe os arquivos de fonte da pasta `dist`.
2. Instale os arquivos de fonte.
3. Copie os ícones da [documentação](https://matheusmcuba.github.io/icones-bancos-brasileiros/) e cole-os utilizando a fonte instalada.

## Novos ícones

Para novos ícones de bancos, sinta-se à vontade para desenhar e contribuir, ou abra uma _issue_ com os detalhes do ícone que você precisa para ele entrar em uma próxima _release_.
